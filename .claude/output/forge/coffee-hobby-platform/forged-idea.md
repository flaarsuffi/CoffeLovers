# CoffeLovers — Plataforma de Café Caseiro

## Visão
Plataforma web responsiva para ensinar entusiastas e iniciantes a dominar a arte de fazer café bem feito em casa.

## Escopo

### Público
- Principal: entusiastas de café caseiro
- Secundário: iniciantes que consigam acompanhar

### Conteúdo Mínimo
- **10 grãos** mais consumidos/populares no Brasil
- **5-6 métodos** acessíveis (V60, Aeropress, French Press, Italiana, coado, etc)

### Estrutura de Conteúdo

**Grão:**
- Origem/história
- Perfil de sabor
- Métodos recomendados (2-3)
- Receita sugerida

**Método:**
- Tutorial passo a passo
- Equipamentos necessários
- Técnica (temperatura, tempo)
- Variações de receita

## Arquitetura do Site

- **Home** — explicação + quiz interativo (8 perguntas)
- **Grãos** — lista + páginas de detalhes
- **Métodos** — lista + páginas de detalhes

## Quiz
- Perguntas: nível de conhecimento, paladar, tempo disponível
- Resultado: 2 métodos + 3 grãos sugeridos
- Links para páginas específicas

## Navegação
- Grão → recomenda método (link)
- Método → não precisa linkar para grão

## Design
- **Tom:** casual e amigável
- **Visual:** dinâmico, animações estratégicas
- **Diferencial:** informação unificada, experiência amigável (vs blogs dispersos)

## Produção de Conteúdo
- Conteúdo criado por IA (agentes de pesquisa)
- Planejamento de agentes: próxima sessão de clarificação
